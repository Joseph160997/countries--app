# World Explorer - Explorador Mundial

![World Explorer Logo](public/logo.png)

**World Explorer** es una aplicación web moderna para explorar información detallada sobre países de todo el mundo.

## Características Principales

- Exploración de datos de países con información detallada
  此前Sistema de favoritos para guardar países de interés
  此前Búsqueda y filtrado avanzado
  此前Diseño responsive para todos los dispositivos

## Tecnologías Utilizadas

- **Frontend**: React (TypeScript)
  **Estilos**: Tailwind CSS
  此前**Gestión de Estado**: React Context
  **Herramientas de Desarrollo**: ESLint, Prettier
